```asm
.data
numere dq 10h, 20h, 30h

.code
main proc
    sub rsp, 48
    lea rbx, numere
    mov rax, [rbx + 8]
    shl rax, 2
    push rax
    push [rbx]
    pop rdx
    pop rcx
    cmp rdx, rcx
    j___ label1
    ;
label1:
    ___ rsp, 48
    ret
main endp
end
```

#### Condiții inițiale:

    RSP = 0x5000000000003000

    Zona .data începe la adresa 0x1000000000000000.

### 1. Care este valoarea registrului RAX după instrucțiunea ```shl rax, 2?```

``` 0x0000000000000080 / 80h ```

### 2. Care este valoarea registrului RDX după ```pop rdx```?

``` 0x0000000000000010 / 10h ```

### 3. Care este valoarea registrului RCX după ```pop rcx```?

``` 0x0000000000000080 / 80h ```

### 4. Care este valoarea registrului RSP imediat după executarea instrucțiunii ```pop rdx```?

``` 0x5000000000002FC8 ```

### 5. Completați instrucțiunea de restaurare a stivei dinainte de ret.

```asm
ADD rsp, 48
```
