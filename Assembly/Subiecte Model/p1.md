```asm
.data
v dd 11223344h, 55667788h, 99AABBCCh

.code
main proc
    sub rsp, 32
    lea rsi, v
    mov rcx, 1
    lea rbx, [rsi + rcx*4]
    movzx r10, word ptr [rbx + 2]
    push r10
    push rsi
    pop r11
    pop rax
    cmp r10, rax
    j___ skip
    ;
skip:
    ___ rsp, 32
    ret
main endp
end
```

#### Condiții inițiale:

RSP = ```0x7FFF000000001000```

Zona .data începe la adresa ```0x4000000000000000```.

### 1. Care este valoarea registrului R10 după executarea instrucțiunii ```movzx```?

``` 0x0000000000005566 / 5566h ```

### 2. Care este valoarea registrului RSP după executarea instrucțiunii ```pop r11```?

``` 0x7FFF000000000FD8 ```

### 3. Care este valoarea registrului R11?

``` 0x4000000000000000  ```

### 4. Care este valoarea registrului RAX?

``` 0x0000000000005566 / 66h ```

### 5. Ce instrucțiune de salt condiționat trebuie pusă la ```j___``` pentru ca saltul la skip: să aibă loc când R10 este egal cu RAX?

``` je skip / jz skip ```
